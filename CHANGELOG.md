# Changelog

All notable changes to this project will be documented in this file.

This project follows the spirit of [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.0.2] - 2026-03-03

### Added

- ONNX Runtime-backed Flutter text-to-speech plugin for Android and iOS.
- Multi-language IPA mapping support for English, Indonesian, Swahili, and Spanish.
- Speaker selection for supported English voice variants.
- Viseme timing output for lip-sync and mouth animation workflows.
- Separate `generateVoice` and `playVoice` APIs for applications that need to control synthesis and playback independently.
- Configurable request options for model paths, language, speaker, speed, sample rate, and native thread count.

### Documentation

- Added project governance, contribution, and MkDocs documentation files.

### Added
